# 🤖 Generative AI Laboratory

Welcome to my **Generative AI Laboratory** repository!

This repository contains a collection of hands-on experiments and projects
developed as part of my Generative AI laboratory work. The experiments explore
Large Language Models (LLMs), Prompt Engineering, Retrieval-Augmented Generation
(RAG), Multimodal AI, Diffusion Models, Fine-Tuning, and deployment of
Generative AI applications.

---

## 📌 About This Repository

The objective of this repository is to gain practical experience in building
Generative AI applications using modern AI models, frameworks, APIs, and tools.

Each experiment contains:

- 💻 Source Code
- 📖 Experiment Documentation
- 📸 Output Screenshots
- 🛠️ Technologies Used
- ▶️ Execution Instructions
